# Первый Пилот

Архив газеты 1996–2007 годов. React + TypeScript + Vite, Pages Functions + D1/R2; публичный frontend подготовлен к размещению в Selectel.

## Локальный запуск

```sh
npm ci
npm run dev
```

Открыть http://127.0.0.1:4173. Изменения исходников обновляются автоматически. Локальные PDF и обложки берутся из `archive-data/archive`, они не входят в сборку интерфейса.

## Проверка и сборка

```sh
npm run typecheck
npm test
npm run build
```

`dist/` — публичный frontend для российского сервера. `npm run build:admin` создаёт `dist-admin/` для Pages. `npm run deploy` собирает и публикует только админку Cloudflare; не обновляет российский сайт.

`archive-data/` содержит восемь восстановленных PDF, небольшие обложки и контрольные суммы. Архив публикуется отдельно от frontend. Изображения страниц создаются PDF.js при чтении; генерация всех страниц на сервере не нужна.

## Настройка инфраструктуры

[Плейбук Cloudflare и Selectel](docs/SELECTEL-PLAYBOOK.md) описывает порядок запуска, перенос архива, DNS, HTTPS, проверки и откат.

[Отчёт восстановления](docs/RECOVERY.md) описывает происхождение исходников и ограничения восстановления.

Не помещать единственную копию проекта в `/tmp`. После каждого изменения создавать Git-коммит; хранить отдельный Git bundle или удалённую копию репозитория.
