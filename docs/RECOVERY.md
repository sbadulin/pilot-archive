# Восстановление проекта

Дата: 13 сентября 2026.

Исходная рабочая папка `/private/tmp/pervyi-pilot-prepared` не найдена. Причина её исчезновения не установлена. Пустой `/Users/serccu/repos/pervyi-pilot` содержал только README и начальный коммит.

Исходники восстановлены из локального журнала Codex с началом 8 сентября: извлечены только записи файлов и изменения текста в хронологическом порядке. Исторические команды деплоя, удаления, обращения к сервисам и Git push не выполнялись. Журнал целиком не включён в проект, поскольку может содержать учётные данные.

Восстановлены React-компоненты, CSS, каталог восьми выпусков, формы загрузки и проверки, Pages Functions, SQL-миграция, конфигурация Cloudflare и документация. Восемь PDF и логотип найдены в Downloads. PDF скопированы без изменения содержимого; размеры и SHA-256 находятся в `archive-catalog/checksums.json`. Обложки повторно получены из первых страниц.

История старых Git-коммитов не восстановлена: объектов прежнего репозитория нет в найденных копиях. Новая история отмечает восстановление явно; старые хеши не воспроизводятся искусственно.

После извлечения исходников отдельно подготовлена публичная сборка для Selectel: PDF исключены из frontend, PDF.js рисует страницы по мере просмотра, его ресурсы и шрифты раздаются локально. Админка размещается на pages.dev.

Удалённые D1 и R2 этим восстановлением не изменялись. Заявки, загруженные через сайт, хранятся там и не представлены восемью локальными PDF. Перед миграцией их необходимо выгрузить отдельно.

Старый код прямой загрузки Selectel найден в незавершённом состоянии. Подпись SigV4 исправлена и проверена по контрольному примеру AWS. Протокол завершения загрузки, повторов публикации и синхронизации каталога требует отдельной интеграционной проверки; не включать Selectel uploads только установкой секретов до прохождения плейбука.
