# Поиск по авторам

Человек вводит имя или псевдоним — сайт показывает, в каких номерах и на каких страницах он подписывался. Каталога авторов нет: только поле поиска. Схема — `migrations/0002_authors.sql` (D1 `pilot_archive`).

## Данные

- **credits** — одно имя в одном материале: номер (год/номер/сквозной, как в `manifest.json`), лист PDF (`sheet`), печатная страница (`printed_page`), рубрика, подпись как напечатана (`byline`), чистое имя (`name`) и его ключ поиска (`name_key`). Подпись «Откровение VIRUS'а записали Sly и Neo» даёт две записи: «Sly» и «Neo».
- **recognition_runs** — какой лист какой моделью распознан. Повторный прогон пропускает готовые листы; листы с `refused` (отказ модерации Gemini) уходят на Sonnet.

Номер задаётся тройкой год/номер/сквозной: у старых номеров нет строк в `issue_submissions`.

## Как появляются записи

1. Распознавание листа (Gemini 3.8 Flash, при отказе — Claude Sonnet) возвращает материалы: `title`, `byline`, `authors[]`.
2. На каждое имя из `authors[]` создаётся `credit` со `status = 'auto'`.
3. Куратор может исправить имя, подтвердить (`confirmed`) или скрыть (`hidden`) запись.

## Ключ поиска `name_key`

`normalizeName(name)`:
- нижний регистр, `ё → е`;
- латинские двойники в кириллических словах → кириллица («К.О.Т.Т.», набранное вперемешку, даёт один ключ);
- убрать пунктуацию и кавычки, схлопнуть пробелы.

Записи с одинаковым ключом показываются в поиске одним вариантом («Васисуалий ЛОПАТА» — все его материалы).

## Поиск на сайте

- Срабатывает от 3 символов. Запрос нормализуется так же, совпадение — по началу любого слова имени («тиш» находит «Князь Тишины»), с допуском на одну опечатку для запросов от 5 символов.
- Выпадающий список вариантов: имя и число материалов. Выбор варианта — список материалов: номер, дата, страница, рубрика; ссылка `#issue-<year>-<number>-<serial>-p<page>`.
- Индекс — статический `archive/authors-index.json` в публичном бакете Selectel, собирается так же, как `manifest.json` (при одобрении номера и после правок куратора):

```json
{
  "version": 1727700000000,
  "names": [{ "name": "Князь Тишины", "key": "князь тишины",
    "credits": [{ "issue": "2000-26-0091", "page": 7, "kind": "article", "title": "Кидайте их, пацаны!" }] }]
}
```

Без пейджера это порядка 40 имён на номер, файл остаётся небольшим. Когда добавится пейджер (сотни имён на номер), индекс делится на файлы по первым трём буквам каждого слова (`authors-index/тиш.json`) и грузится по запросу — порог в 3 символа как раз это позволяет.

## Лист и печатная страница

Распознаётся лист PDF, а ссылка ведёт на печатную страницу: после разворота они расходятся (лист 11 = страница 12). `printed_page` считается при распознавании той же логикой, что `printedPages()` в `src/readerLayout.ts`, и для разворота берётся первая страница.

## Позже: связь ников

Для постоянных авторов добавим таблицы автора и его псевдонимов: поиск по любому нику будет находить все материалы человека. Связь псевдонима с настоящим именем на сайте не показывается без согласия автора. `credits` для этого менять не нужно — связь строится по `name_key`.
