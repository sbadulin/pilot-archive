# Первый Пилот

Архив газеты 1996–2007 годов: публичный сайт `pilot-archive.ru` и админка куратора на Cloudflare Pages. React, TypeScript, Vite, Pages Functions, D1, R2, Selectel S3. Запуск описан в [README](README.md).

Репозиторий публичный. Сюда не попадают секреты, оригиналы выпусков и данные из локальных кэшей.

## Проверка

```sh
npm run check         # типы, тесты, каталог архива, обе сборки
npm run test:browser  # Playwright
```

Браузерные тесты читают PDF с живого сайта. Если сломан выпуск № 01 на сайте, они падают и без изменений в коде.

Если правка ослабляет тест, таймаут или проверку каталога, назови это в описании PR отдельной строкой.

## Ветки и выкатка

- Работа идёт в ветке, в `main` попадает только через PR.
- Слияние в `main` сразу выкатывает прод: фронтенд в Selectel, админку в Pages.
- Перед `gh pr merge` дождись зелёной проверки `Tests and builds` через `gh pr checks <n> --watch`, даже если просят слить немедленно. Локальный `npm run check` её не заменяет.
- Когда проверка зелёная и пользователь хочет видеть правку на сайте, сливай сам.
- Миграции D1 не применяются при деплое. Это отдельная операция с резервной копией, см. [GITHUB.md](docs/GITHUB.md).

## Архитектурные запреты

- Публичный сайт должен работать из России, поэтому он не зависит от Cloudflare и D1. Он читает статические файлы из бакета Selectel. D1 служит только рабочим хранилищем куратора.
- Cloudflare работает на бесплатном плане, это около 10 мс CPU на запрос. Тяжёлую работу в Pages Functions не делай, её выполняет браузер куратора. Перестроение индекса на сервере уже давало HTTP 503.
- Код куратора попадает только в сборку админки, через `__ADMIN__` в `build.mjs`.

## Цензура

Правила и типы решений описаны в [REDACTION.md](docs/REDACTION.md). Читай его перед любой правкой `redactions.json`, `src/riskTerms.ts` или `scripts/redaction-rules.json`.

- Юриста у команды нет. Решения «показать юристу» не бывает: спорное закрывается минимальным фрагментом.
- Плашки только чёрные, без надписей, и не задевают соседний текст. На скошенной колонке используй `{ region, hug: true }`, а не прямоугольный `box`.
- Каждую ручную рамку проверяй на крупной вырезке до применения.
- Закрытая подпись или заголовок убираются и из публичного индекса авторов.

## Выпуски и Selectel

Порядок работы с выпуском описан в [PUBLISHING.md](docs/PUBLISHING.md), пейджер в [PAGEER.md](docs/PAGEER.md).

- Цензура идёт до «Одобрить»: одобрение копирует файл в публичный бакет как есть.
- Кнопку «Одобрить» нажимает пользователь. Пейджер и графику выкладывай только после этого: ссылки пейджера ведут на выпуск, а миниатюры графики строятся из публичного PDF.
- Загрузка в Selectel из-за границы обрывается, а незавершённый PUT убирает выпуск с сайта (ответ 409). Загружай через российский сервер: `scripts/stage-issue.sh`, `scripts/publish-redacted.mjs`.
- Удалять из публичного бакета нашим ключом нельзя, только перезаписывать.
- Командам `aws`, `pager:publish` и `graphics:publish` нужны `AWS_CA_BUNDLE=/etc/ssl/cert.pem AWS_PROFILE=selectel`. Без них aws cli падает с ошибкой «self-signed certificate», VPN тут ни при чём.
- Кэш распознавания авторов оплачен деньгами, не удаляй и не пересоздавай его. Кэши лежат рядом с оригиналами, корень задаёт `PILOT_ARCHIVE_ROOT` (по умолчанию `~/Downloads/Reading`).

## Каталог графики

Разметка лежит в кэше, в `graphics/<id>.json` и `graphics/crops/`, в репозиторий не входит. Решения редактора записаны в `scripts/graphics-artists.json`: `include`, `exclude`, `reprints`, `titles`.

```sh
npm run graphics:site                # миниатюры из публичных PDF
npm run graphics:publish -- --apply  # с переменными AWS из раздела выше
```

На мелких вырезках чужие метки похожи на подпись Захара Веселова («В.» в овале над годом). Найденную метку покажи редактору, прежде чем записывать рисунок на его счёт.
